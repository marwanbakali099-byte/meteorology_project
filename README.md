# 🌦️ Projet de Surveillance Météorologique (Meteorology Project)

## 📌 Présentation
Ce projet est une application de visualisation et d'analyse de données climatiques. Il permet de récupérer, de traiter et d'afficher des informations météorologiques précises (**température, humidité, pression**) en temps réel ou à partir de données historiques.

---

## 🚀 Fonctionnalités Clés
* **Visualisation en Temps Réel :** Intégration d'API météo pour des prévisions actualisées.
* **Analyse de Données :** Calcul automatique des moyennes, des minimales et des maximales quotidiennes.
* **Interface Moderne :** Design épuré avec un effet **Glassmorphism** (verre dépoli) pour une expérience utilisateur immersive.
* **Tableau de Bord Graphique :** Utilisation de graphiques interactifs pour suivre l'évolution des précipitations et des températures.

---

## 🛠️ Stack Technique
* **Frontend :** HTML5, CSS3 (Flexbox/Grid), JavaScript (ES6+).
* **Traitement de données :** Python (Pandas/NumPy) pour l'analyse statistique.
* **Source de données :** OpenWeatherMap API ou fichiers de données historiques (CSV/JSON).
* **Visualisation :** Chart.js ou D3.js pour les rendus graphiques.
